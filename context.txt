4. RING BUFFER
--------------
Vreau să implementez eu un ring/circular buffer.
Structură conceptuală:
typedef struct {
    packet_t buffer[64];
    size_t head;
    size_t tail;
    size_t count;
    pthread_mutex_t mutex;
    pthread_cond_t not_empty;
    pthread_cond_t not_full;
} ring_buffer_t;
Ring buffer-ul trebuie să fie thread-safe.
Trebuie să învăț:
- mutex
- condition variable
- producer/consumer
- blocking
- spurious wakeups
- while vs if la pthread_cond_wait()
- queue full
- queue empty
- race conditions
Exemplu conceptual:
RX thread:
    receive packet
    lock
    dacă bufferul este full -> wait
    introduce packet
    signal not_empty
    unlock
Worker:
    lock
    dacă bufferul este empty -> wait
    scoate packet
    signal not_full
    unlock
    procesează packet
IMPORTANT:
Nu vreau busy waiting.

Mă interesează în special:
- C
- Embedded C
- Linux
- POSIX
- RTOS concepts
- concurrency
- synchronization
- networking
- debugging
- system design
Nu vreau să transform proiectul într-un proiect de algoritmică. Algoritmica o stăpânesc deja.
Vreau să mă concentrez pe:
"Cum funcționează un sistem software real care are mai multe thread-uri/procese, network I/O, shared state, synchronization, failure recovery și resource management?"
38. CRITERIU DE FINALIZARE
--------------------------
Proiectul este considerat terminat când:
- poate primi și transmite packet-uri;
- are protocol propriu;
- are RX thread;
- are ring buffer thread-safe;
- are worker pool;
- are firewall;
- are CLI;
- are statistics;
- are logging;
- are atomic counters;
- are watchdog;
- are cel puțin două procese;
- folosește shared memory;
- folosește pipe IPC;
- are TCP control interface;
- are poll/event loop;
- are firmware A/B simulation;
- poate simula power loss;
- are rollback;
- are graceful shutdown;
- are teste;
- rulează fără memory leaks detectabile;
- rulează sub sanitizers;
- are Makefile;
- are README cu arhitectură și explicații.
IMPORTANT:
Vreau ca proiectul să fie construit incremental, iar fiecare etapă să fie înțeleasă înainte de următoarea.
